# API 工作台

主要用户是查询、调试和集成接口的开发者。页面围绕接口目录、契约参考和请求调试组织，宿主提供服务契约与身份能力。

- 桌面默认目录、参考、调试三列；内容区域不足时调试区排在参考下方。目录可调整宽度，已有窄屏抽屉保持行为。
- 契约控制目录标签、方法、协议、字段、枚举、弃用和下线提示；不按业务名或路由推测含义。
- 所有凭证仅保存在内存，cURL 使用敏感值占位符，请求限制同源并拒绝重定向；401 不自动重放。
- 按接口在当前页面内存中保留请求草稿、响应与调试页签；切换接口取消未完成请求，重置按钮清空本接口请求与响应，刷新页面后清空全部会话。
- 全局认证与请求头明确标出继承范围；接口覆盖仅影响本接口。新增授权先显示填写提示，点击应用时校验，错误不提交。
- 目录默认收起低频筛选，显示已启用筛选数量；单一协议时省略目录内重复协议标签。概览给出调试步骤与首个接口入口。
- 参数区分缺省与显式空字符串。请求编辑区按内容自适应高度并保留手动调整；收到响应后让结果进入视野。请求和响应使用统一代码阅读与编辑样式，编辑器、语言和 Worker 随入口交付。
- 中文/英文 UI 由模块 i18n 提供，契约原文保持原样。普通文字使用系统无衬线字体；代码使用随包分发的 JetBrains Mono，保留 OFL 许可证。
- 操作使用语义按钮、可见焦点、加载/空/错反馈；Escape 关闭弹窗并恢复焦点，接口切换聚焦标题。reduced-motion 关闭非必要动画。
- 新变更仅要求 PC 的 1366×768、1440×900、1920×1080；已有移动端行为不删改。

视觉与交互变更应验证示例页面，结构迁移应验证公开包入口、生产构建与 Worker 依赖闭包。不要为了迁移更换设计语言。
