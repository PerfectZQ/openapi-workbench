# API 工作台

主要用户是查询、调试和集成接口的开发者。页面围绕接口目录、契约参考和请求调试组织，宿主提供服务契约与身份能力。

- 桌面默认目录、参考、调试三列；内容区域不足时调试区排在参考下方。目录可调整宽度，已有窄屏抽屉保持行为。
- 契约控制目录标签、方法、协议、字段、枚举、弃用和下线提示；不按业务名或路由推测含义。
- Basic、API Key 与 OAuth2 Bearer 凭据按 Swagger 声明配置；契约加载与请求调试可共用同一宿主身份提供方，401 通知登录状态，403 显示权限失败，两者都不重放请求。
- 所有凭证仅保存在内存，cURL 使用敏感值占位符，请求限制同源并拒绝重定向；401 不自动重放。
- 按接口在当前页面内存中保留请求草稿、响应与调试页签；切换接口取消未完成请求，重置按钮清空本接口请求与响应，刷新页面后清空全部会话。
- 全局认证与请求头明确标出继承范围；接口覆盖仅影响本接口。新增授权先显示填写提示，点击应用时校验，错误不提交。
- 目录首页按一级标签列出全部模块和接口数，概览展示模块标识和真实子分类。进入模块后固定模块名、返回索引和定位当前接口的入口，子目录可展开，每层的接口名与同级目录名沿同一文字列对齐。直属接口与子目录分区。宿主可用 `moduleLabel` 提供本地化名称，原标签仍可检索。
- 搜索和协议、方法、生命周期筛选跨模块匹配，同一逻辑操作的多个协议按契约 `x-api-operation` 合为一个目录项，独立版本化路由可直接发现。结果按完整目录路径分组。目录支持方向键和 Home / End，搜索框内向下移入结果，输入法完成组合后 Enter 打开首个匹配，Escape 清除查询。
- 参考区按“模块路径、接口名、协议与方法路径、说明、字段”阅读。多协议使用一个带选中态的切换器，具体 Action 与 Version 可直接查看和复制。较长的多段说明可展开全文，多个认证组合可展开核对。字段表将剩余宽度优先留给说明。
- 带请求体且无查询或路径参数的接口直接编辑请求体。全局认证及公共 Header 保留独立入口，配置校验失败将焦点移到出错分页的说明。空响应仅占一行，收到响应后展示状态与正文。
- 参数区分缺省与显式空字符串。请求编辑区按内容自适应高度并保留手动调整；收到响应后让结果进入视野。请求和响应使用统一代码阅读与编辑样式，编辑器、语言和 Worker 随入口交付。
- 中文/英文 UI 由模块 i18n 提供，契约原文保持原样。普通文字使用系统无衬线字体；代码使用随包分发的 JetBrains Mono，保留 OFL 许可证。
- 操作使用语义按钮、可见焦点、加载/空/错反馈；Escape 关闭弹窗并恢复焦点，接口切换聚焦标题。reduced-motion 关闭非必要动画。
- 全局补充说明统一使用 `ui/HelpTip`。默认入口采用 16px 的圆圈叹号，细圆环内居中放置短竖线与圆点。20px 排版区域保持居中，24px 命中区域不挤占文字。默认中性灰且无底色，悬停、聚焦和展开时使用品牌蓝与浅蓝圆形背景。业务页面只安排位置和内容，不覆盖图标、内边距、尺寸或透明度；模式切换等按钮组的样式限定到直接所属按钮，避免污染嵌套帮助入口。
- 帮助浮层共用白色表面、圆角和投影 token，16px 内边距、8px 标题正文间隔；标题与关闭入口固定，长说明在正文内滚动。复制原值、自定义入口与操作区继续共用定位和焦点机制；悬停预览、点击固定、Escape 关闭、视口避让和 reduced-motion 保持一致。
- 表头排序使用 `ui/SortHeadingButton`。同一位置显示两枚上下排列的箭头，当前方向用品牌色标出，切换时文字与图标位置保持稳定。业务页面提供下一次操作的可访问名称及表头的 `aria-sort`，并负责决定首次排序方向与处理排序。
- 新变更仅要求 PC 的 1366×768、1440×900、1920×1080；已有移动端行为不删改。
- 原生滚动条与 Monaco 共用中性灰滑块，默认清晰可辨，悬停或聚焦时加深，拖动时使用次要文字色；横纵轨道与滑块尺寸在不同状态下保持一致。桌面正文滚动区通过 `ui/ScrollHints` 与 `data-scroll-hints` 统一提示后续内容：下方仍有内容时在末端 24px 内渐隐，距离底部不足 24px 时随剩余距离收回，到底或无溢出时完整显示。仅对正文下沿应用遮罩，保留原生滚动条、表头及顶部控件；标题、关闭与底部动作仍独立固定。内容加载、筛选、折叠与窗口缩放后重新计算，不持续轮询或驱动 React 逐帧渲染；reduced-motion 下取消短过渡，高对比度模式关闭渐隐，鼠标、触控板和键盘继续使用原生滚动。

视觉与交互变更应验证示例页面，结构迁移应验证公开包入口、生产构建与 Worker 依赖闭包。不要为了迁移更换设计语言。
