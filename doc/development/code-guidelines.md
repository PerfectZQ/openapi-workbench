# 代码规范

目录按模块职责组织，文件与函数名称表达用途。共性只有一个事实来源，不通过转发包或空接口堆叠层次。

先对齐场景、预期、边界和最终目标，再实现已存在的需求。Provider 是真实语言边界，当前仅 Go 与 TypeScript；不预建未来语言。方法按契约解析、类型映射、源码输出、文件/归档等阶段拆分，避免过大函数。

共享输入只读，Provider 每次创建独立模型状态。错误必须带可定位的语言、方法或模型上下文，不能静默丢弃字段。生成文件不得手改；结构迁移保持公开方法、路径、类型和传输行为，变更时提供对应契约证据。

存在可用 CodeGraph 索引时先用它定位，再用 rg 核查影响。没有索引直接使用常规工具，不自动初始化。Go 使用 1.26.4 与 gofmt；前端使用 Node.js 24 和锁定依赖。
